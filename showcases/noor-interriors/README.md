# GARA INTERIORS

A complete, standalone interior design showcase for Gara Tech Software Solutions.

Open **index.html** directly in a browser. No installation, build, server, libraries, or network connection is needed. For GitHub Pages, publish the repository root from the selected branch. All URLs are relative and work under a repository subpath.

## Experience

- Editorial portfolio with accessible project dialogs and contextual project-start links.
- Scroll-driven room reveal, desktop horizontal collection story, and mobile swipe gallery.
- Six-material explorer, five-mood selector, and matched before/after range control.
- Native service disclosures, animated FAQ, counters, floor-plan timeline, and reduced-motion alternatives.
- Six-step project brief with validation, local reference-file selection, editable summary, and text download. All personal data stays in memory; reloading clears it. Reference files are listed by name in the download, not uploaded or embedded.

## Editing

Content and form options are in `index.html`; design tokens and responsive styles are in `style.css`. Project details, material/mood descriptions, and scroll stages are in `script.js`. Studio statistics use `data-count` and `data-suffix` attributes in the HTML. Replace the demo contact details and social homepage links before using this for a real business.

The project names, locations, testimonial and studio statistics are fictional showcase content, disclosed on the page. Prices are indicative budget choices in AZN, not estimates. This site sends no enquiries.

See `assets/CREDITS.md` for photography and font sources. The before image is an AI-assisted visualization of the same room, not documentary renovation photography; the wardrobe and photographic material atlas are generated concept images. The floor-plan drawing is a code-native illustration.
